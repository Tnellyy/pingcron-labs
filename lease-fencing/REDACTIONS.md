# Public derivative policy

Retained local originals are unchanged. Reviewed Python source and synthetic SQLite databases are byte-identical. Public text records replace local lab, article, workspace, interpreter and user-home paths with [LAB_ROOT], [ARTICLE_ROOT], [WORKSPACE], [PYTHON] and [USER_HOME]. UTF-8 BOMs are removed when decoding text. No observed numbers, timestamps, PIDs, statuses, errors, payloads, source hashes or assertions are changed. Placeholder commands are provenance; use the README command to run.

All six recorded suites are included, including earlier failed checks and independent runs. Python bytecode caches, account/browser captures, X research, private product material and unrelated files are excluded. The downloadable archive includes full per-run transcripts and synthetic databases. Top-level GitHub files expose source, docs and aggregate results; remaining per-case evidence is in the archive.

MANIFEST.json maps each evidence file to original/public SHA-256 and its transformation. Authored release README/this policy are packaging documentation, not execution records. ZIP-SHA256.txt is outside the archive to avoid self-reference.
